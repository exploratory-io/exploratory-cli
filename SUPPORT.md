# Support

| You need | Where to go |
|---|---|
| A bug in the CLI or a feature request | [Open an issue](https://github.com/exploratory-io/exploratory-cli/issues/new/choose) in this repository |
| Help using Exploratory, your account, or a problem in Exploratory Desktop or Exploratory Server itself | support@exploratory.io |
| A security problem | See [SECURITY.md](https://github.com/exploratory-io/exploratory-cli/blob/main/SECURITY.md); do not open an issue |

We do not promise a response time. Never paste tokens, passwords or customer data into an issue.
