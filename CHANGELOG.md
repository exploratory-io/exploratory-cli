# Changelog

The npm package has its own version, starting at 1.0.0. Each version is built from the `expl` in a released Exploratory Desktop, or in a tam master commit, and the first line of its section names that Desktop version, and the tam commit when it was built from one. Tools added on the Exploratory Server side do not need a new version of the CLI, because the command list is fetched from the server at run time.

## 1.0.0 - 2026-11-23

Built from the `expl` in Exploratory Desktop 17.0.5.
